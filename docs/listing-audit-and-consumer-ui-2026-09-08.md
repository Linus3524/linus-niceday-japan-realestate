# 圖紙核對與前台呈現

## 已實作

- 內部核對層保存修正前辨識文字，區分辨識記載、程式修正、模型暫估與缺漏。辨識文字不冒稱人工查證原文。
- 依租賃、公寓、土地、透天、整棟及住宿用途檢查必要欄位；區分0円與未載明。
- 核對新舊價格、完整樓層合計、同列平方米與坪數、營收與刊載投報率、許可狀態及交付矛盾。
- 價格、適用面積或行情必要欄位未確認時，停止行情高低價結論。押金／禮金未知顯示「待確認，未計入」，不宣稱免收。

## 前台取捨

依使用者回饋，不展示內部缺項數量、修正紀錄與逐欄來源清單。只有會影響試算的問題才顯示一句具體原因，例如「平方米與坪數記載不一致，確認面積後才能比較行情」。其他資料留在原有費用、交屋或許可模組。

同業流通資訊在呈現前過濾，涵蓋取引態様、業者手數料、AD、刊登限制、定休日等。租客實際事務費、更新費及物件交付條件保留；原始分析資料不被這層顯示過濾覆寫。

特殊買賣區改用主分析頁面一致的小型綠色標題、圖示、白底資料區、細邊框與數值卡片，移到基本規格之後。移除整塊外層底色、嵌套格子與常態黃色許可框；僅真正異常採提示色。

## 驗證與限制

- `test:listing-audit`：缺漏與零值、來源保留、價格／面積／許可／收益矛盾、全形及平方米變體、部分樓層不誤判。
- `test:consumer-listing`：內部資訊隱藏、重要租客費用保留、正常物件無核對清單、異常物件只呈現具體結果。
- 原13張買賣與租賃費用回歸通過；前13張買賣及後樂園租賃PDF的真實辨識回應重播至完整上傳頁面，逐張檢查1440px桌面及390px手機，無橫向溢出或頁面腳本錯誤。
- 後樂園PDF另實際呼叫更新後API，確認回應包含核對結果及原始辨識欄位。UI重播的外部定位使用固定回應，不宣稱重測外部路線。
- 型別檢查與建置通過；新測試已加入CI。未部署。

這些是規則防呆與既有案例回歸，不是所有排版的OCR保證。未實測全套模糊／旋轉影像，也未建立正式環境監控；保留這些作為後續擴充範圍。
