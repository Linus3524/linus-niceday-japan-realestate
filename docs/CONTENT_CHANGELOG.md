# 內容更新紀錄

本紀錄用於追蹤網站知識內容的修改。每次涉及法規、金融、行情、民泊或 AI 知識的重要更新，都應新增一筆紀錄。

## 2026-09-05｜買賣雙基準與屋齡資料化

- 租賃圖紙行情由 210 個精選地區擴為全 47 都道府縣、1,192 個有公開租金值的市區町村、4,785 個格局值；地圖與車站推薦維持原精選範圍。
- 修正空白車站可能讓無法辨識的地址誤配到第一個行政區，以及沖繩、姬路、濱松等新舊字形的全國地址比對。
- 國交省成交快照由原 210 地區擴為全 47 都道府縣、506 個有合格樣本的市區町村、1,389 個市區町村／格局分桶；地址解析同步全國化。
- 新增 At Home 中古公寓公開刊登靜態快照：498 個市區町村、1,689 個有效格局值；SUUMO 與 HOME'S 以全國交叉核對入口呈現，不混算不同統計口徑。
- REINS 開價備援擴到首都、中部、近畿三圈；西日本公開摘要只有成約價時保持缺值。
- 新增東日本 REINS 2026-07 首都圈中古公寓成約／新規登錄㎡單價常數，買賣圖紙同時顯示成約行情與市場典型開價。
- 明示 REINS 是兩組市場物件的平均差距，不把 28.6% 的反向差距冒充個案必然議價幅度。
- MLIT 快照新增成交㎡單價、代表面積、建築年覆蓋、構造計數與至少 5 筆才採用的屋齡分層；全國版 953／1,389 個粗分桶已有合格屋齡子分桶。
- 估價改為優先使用「同區 × 同房型 × 同屋齡帶㎡單價」，不足時回退同區同房型㎡單價；避免同時再加一次手估屋齡係數。
- 補上非塔樓最上階 +6% 的獨立處理。
- 複核 At Home、SUUMO、LIFULL HOME'S 公開租金行情入口與統計口徑；三者保留分來源比較，不直接混算。
- 以三軒茶屋、淺草、錦糸町、市川行德 4 份真實販売図面完成端到端回歸；修正可選停車位誤算固定月費、修繕積立金改定額未優先、全面翻新未觸發係數等問題。
- 同房型缺少目標屋齡帶時，新增同區跨房型的屋齡㎡單價備援，並在畫面標明備援口徑與實際分層樣本數。

主要來源：東日本 REINS 月例 Market Watch、國土交通省不動產資訊資料庫 XIT001、At Home／SUUMO／LIFULL HOME'S 公開租金行情頁。

## 2026-09-01｜國交省買賣成交快照啟用

- 啟用國交省不動產資訊資料庫 XIT001 交易資料靜態快照。
- 最新季度為 2026-Q1，共匯入 761 組資料；663 組採最新四季，98 組因近期樣本不足採最新八季，網站 210 個地區均至少涵蓋一種格局。
- 成交中位數改為最新四季優先；四季不足 5 筆時擴大至最新八季，仍不足才回退租金收益率模型，避免舊年度資料稀釋近期行情。
- 每組至少 5 筆交易才採用官方中位數；不足時繼續使用租金收益率模型，避免把小樣本當成行情。
- 更新來源狀態、維護文件與測試，使買房地圖及試算器優先使用相同的成交資料。

## 2026-08-31｜行情更新流程與成交 API 接口

- 建立 At Home、SUUMO、LIFULL HOME'S 與國交省不動產資訊資料庫的來源／更新矩陣。
- At Home 公開頁更新工具按季建立靜態快照，保留缺值與差異檢查。
- 快照保存 13 種原始格局，主畫面以中位數整理為 5 個相近格局群組；`4LDK以上` 不混入 3LDK 群組，避免大型豪宅拉高行情。
- 租金地圖、租屋試算與行情卡新增 `3LDK+`；實測 210／210 個地區有 3LDK 資料。
- 租金快照改為每季檢查、超過 100 天警示。
- 建立國交省 XIT001 買賣交易快照產生器；API 核准前保留空快照，不假造實際成交資料。
- 買房試算器會優先使用合格的國交省行政區／間取り交易中位數；沒有資料時明示沿用租金收益率模型。
- 買房地圖與試算器改用同一個估價函式，避免兩邊的收益率假設不一致。
- 加入國交省 API 規約指定 credit，僅在正式使用該快照時顯示。
- 新增 `docs/MARKET_MAP_BLUEPRINT.md`，記錄現在、累積四季後及取得國交省 API 後的實作邊界。

主要來源：At Home 公開相場頁、SUUMO／LIFULL HOME'S 公開相場頁、國土交通省 XIT001 API 說明與 API 利用規約。
