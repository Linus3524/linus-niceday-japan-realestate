# 網站 UI 用色規則

桌機、平板、手機共用，不能只在桌機 media query 修色。

- 品牌強調：`#00A174`，不再另設深綠、灰綠的按鈕／強調字版本。
- **只有內容上排大型切換鈕**使用 `ui-switch-large`：hover 中性淡灰、選中下半部淡綠漸層＋亮綠底線（章節子主題、稅務階段、融資／民宿制度）。左側目錄、銀行／行政區清單、其他小按鈕不套用漸層，不要全站強制同款。首頁左側主選單保持白色半透明毛玻璃，文字與側線隨人物主題換色，不用選中漸層。
- 下方單色清單（銀行／行政區／章節目錄）：選中使用原本 hover 的較淡綠底，未選中項目 hover 使用中性淡灰；保留綠色側線辨識選中，不加漸層，也不覆蓋首頁毛玻璃或主操作按鈕。
- 交易流程的圖示導覽與左側數字方格是可點擊的步驟定位：兩者同步顯示目前選中步驟，使用品牌亮綠實心底＋白字／白圖示，不使用半漸層。只捲動章節內容，並尊重減少動態效果設定。
- 一般內容卡：白底、標準細框，用留白與分隔線建立層級；不要把整張內容卡染綠。
- 一般實務提醒：使用 `AdviceNote`，方角極淡綠底 `#F2FBF7`、品牌亮綠標題與原本的線條式燈泡（無方塊底）。外框與內部分隔線都是品牌亮綠的 1px 細線，不做表頭粗綠線、頂部色條或側邊粗線；標準版與 compact 版共用同一組色票。
- 例外：租屋「申請與交屋流程 → 實務提醒」是獨立的內容頁，保留原本的大編號、主題標題與白底方角卡，不用燈泡提示卡，也不逐卡重複「Linus 實務提醒」。
- 風險警告／錯誤：保留黃、紅等語意色，不得用一般建議卡取代。
- 費用試算（租屋／買房／圖紙三分頁）外觀跟租屋、買房分頁一致：只有最上排「租屋／買房／圖紙」切換列用 `calc-switch` ＋ `ui-switch-large`（半漸層＋綠底線），下面的「描述需求／選擇條件」等次層切換不再用漸層，選中只用淡綠底＋綠字，避免跟上排重複；按鈕文字跟其他分頁一樣繼承明體，不另外強制 `font-sans`（金額為主的資料卡、`font-jp` 日文地名除外）；區塊外框、表單控制項用 `#DDE3DF`／`#C9D2CD` 細線，不用墨黑粗框；小選項選中用 `#F0FAF6` 淡綠底＋綠框綠字，不用實心綠／黑塊；條件表單欄用 `calc-form-pane`（上方淡綠往下漸白），重點結果卡用細框＋頂部 2px 綠線；主要動作按鈕用品牌綠實心，不用純黑。
- 費用試算的金額漲跌、熱力圖、交通線色、LINE／WeChat 識別色、四人物主題色：保留自身語意與識別色，不強制換成品牌綠。
- 正文、次要說明、停用狀態與細線：沿用既有墨色／中性階，不把所有文字換成亮綠。

例：`<AdviceNote>提醒內容</AdviceNote>`；有自訂標題時傳入 `title`，精簡版使用 `compact`。

檢查：`npm run test:brand-colors`、`npm run test:ink-colors`。
