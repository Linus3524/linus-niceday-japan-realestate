# 心理測驗後台統計

2026-10-12 更新：將每日、本月及跨月累計分開，主要畫面先呈現每日開始／完成人次與各區結果比例；詳細回饋、來源、計分版本及追問選項收進可展開的區塊。地區表支援搜尋，並排比較所選期間、本月、累計比例，包含沒有命中的結果。

## 統計口徑

- 開始與完成是事件人次，包含重測，沒有個人識別碼，不能解讀為去重人數。
- 每日依伺服器收到事件的日本時間（UTC+9）歸日；跨午夜作答可能在不同日開始、完成。完成／開始是期間事件比值，並非同一群玩家的完成率。
- 各區比例的分母為該期間已記錄地區結果的完成事件合計；不以開始數或回饋數為分母。
- 語言以測驗端開始作答時記錄的介面語言為準。沒有語言標記的舊資料只算「全部」，所以中文與日文相加不一定等於全部。
- 跨月累計合併現有保留的月資料，查詢自 2026-08 起且最多最近 25 個月，與選定月份無關。不是永久保存的全歷史總數；聚合資料保留 760 天。
- 不同答案組合仍只在月合計提供。每日及跨月累計不能把各月不同組合直接相加，因此顯示未提供。

## 每日資料與相容性

`recordQuizEvent` 在原本月聚合之外，寫入 `linus:quiz:day:YYYY-MM-DD`；語言另存 `linus:quiz:day:zh:YYYY-MM-DD`、`linus:quiz:day:ja:YYYY-MM-DD`。使用同一組驗證過的欄位及原有欄位上限，沒有新增個人資料。

首次記錄時以 SET NX 保存 `linus:quiz:daily-since`。新版部署後才開始逐日累積，首日可能不完整，部署前的月統計不能還原到每天。啟用日前、未來及超出保留期的日期不補零；啟用後保留期內無事件的日子可以顯示零。

`getQuizSummary` 保留原有月欄位及 `byLang`，新增各語言自己的 `dailySince`、`daily`、`cumulative`、`cumulativeFrom`、`cumulativeThrough`。每日與跨月雜湊透過 pipeline 批次讀取，避免逐日逐語言 HTTP 請求。

計分版本格式支援日期及有限長度的調整標籤，例如 `2026-10-12-machida-t2-f4`。原先純日期／單字母版本仍可使用；過去被格式檢查略過的版本欄位不會自動補回。

- `npm run test:admin-metrics`：既有後台統計回歸。
- `npm run lint`、`npm run build`。
- 本機以示範數據渲染實際 `QuizStatsSection`，確認日期／語言／累計切換、地區搜尋、診斷展開、無逐日歷史，以及 390px 手機版。未寫入正式 Redis。
