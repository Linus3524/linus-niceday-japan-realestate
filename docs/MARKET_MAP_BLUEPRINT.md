# 租金／買房行情地圖藍圖

## 目標

讓同一張行政區地圖在租屋與買房模式下使用一致、可追溯的資料來源；格局名稱作為使用者熟悉的入口，實際模型逐步改為「格局群組＋面積帶」。不為了功能數量新增重複地圖，也不在缺少成交資料時製造看似精準的每㎡價格。

## 第一階段：現在執行，不依賴國交省 API

1. **格局口徑一致**
   - At Home 快照保存 1R、1K、1DK、1LDK、2K、2DK、2LDK、3K、3DK、3LDK、4K、4DK、4LDK以上等細格局。
   - 前端改為真正的群組代表值：`1R`、`1K／1DK`、`1LDK／2K／2DK`、`2LDK／3K／3DK`、`3LDK／4K／4DK`。
   - `4LDK以上` 仍保存於細格局快照，但不納入第五組，避免少數都心超大型豪宅拉高代表值。
   - 群組沒有各格局樣本數，不能做假精確的加權平均；採群組內可用行情的中位數，並在資料說明標示為「群組代表值」。

2. **買房估價單一來源**
   - 地圖與試算器共用同一個估價函式。
   - 國交省快照存在時優先使用交易中位數；目前快照為空，統一回退至租金收益率模型。
   - 不再讓地圖與試算器各自維護一份收益率規則。

3. **資料日期與模型狀態透明**
   - 地圖標題使用快照實際年份／日期，不固定寫死「2026」。
   - 買房模式清楚顯示「成交資料」或「租金收益率模型」；目前應顯示後者。

4. **3LDK+ 覆蓋率稽核**
   - 先保存資料並統計 210 個地區的可用率。
   - 覆蓋率達 80% 才在主地圖加入第五組；不足時只放在行政區詳細資訊，避免大量空白按鈕。
   - 實測 210／210 個地區可建立代表值（100%），因此第一階段納入 `3LDK+`。

## 第一階段執行狀態

- [x] 保存 13 種 At Home 細格局並建立 5 個群組代表值。
- [x] 租金地圖、試算器與行情卡加入 `3LDK+`。
- [x] 買房地圖與試算器改用同一個 MLIT 優先、收益率回退的估價函式。
- [x] 地圖改顯示快照的實際資料日期。
- [ ] 國交省成交快照：等待 API 核准，不阻擋目前租金功能。

## 第二階段：累積資料後執行

1. **面積帶**
   - 建議帶：15–24㎡、25–34㎡、35–49㎡、50–69㎡、70㎡以上。
   - 必須取得可按面積篩選的行情或足夠刊登樣本後才做熱力圖；現有固定加減價只保留在試算器，不冒充觀測行情。

2. **三站交叉檢查**
   - At Home 為正式基準；HOME'S、SUUMO 每季同日抽樣。
   - 比較同地區、同建物類型、同格局群組；差異超過 15% 進人工檢查。
   - 先做內部資料品質報告，不在一般使用者主畫面並列三個不同口徑的價格。

3. **歷史變化**
   - 至少累積四季快照後，才顯示年增率或趨勢，避免把單次樣本變化誤稱市場趨勢。

## 第三階段：國交省 API 核准後

1. 買房地圖改以實際交易中位數為主，顯示樣本數及資料期間。
2. 有面積資料時增加總價／每㎡單價切換。
3. 樣本不足的行政區保持收益率模型回退，兩種來源使用不同標示，不混為實際成交。

## 明確不做

- 不新增第二張功能重複的租金或買房地圖。
- 不把三個平台不同口徑的數字直接算術平均後當成真實市場價。
- 不在沒有面積觀測值時製作租金每㎡熱力圖。
- 不在國交省資料尚未匯入時把買房模型描述為成交價。
