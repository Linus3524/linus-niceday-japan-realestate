# 全國街區活動卡片

2026-09-13：全國使用同一個環境卡片。東京保留原有住宅侵入統計、明細與年度趨勢；非東京保留都道府縣犯罪率、評級、全國平均、排名、破獲率及組成，全部直接顯示。左侧統計與右側環境各自標示空間範圍，縣級評級不冒充町丁目住宅風險。

## 資料與算法 v1

- 復用位置查詢的 OpenStreetMap Overpass 結果（24 小時快取），加查 500m 商業場所及 250m 明確標註用途的住宅建物；不使用已截成每類最多三筆的生活設施清單。
- 以節點座標／way 中心到物件定位點的直線距離篩選，不代表返家路線或沿街實況。住宅計算建物數，非戶數。
- 商業包含 shop、餐飲、電影院及娛樂類；娛樂為 bar/pub/nightclub/karaoke、遊戲場類。店家同 ID 去重，另將 30m 內同名同類型 node/way 合併；匿名重複場所仍可能存在。
- 娛樂至少 8 處且商業至少 20 處 → 娛樂集中；否則商業至少 35 處 → 熱鬧商圈；住宅至少 5 棟且商業至少 8 處 → 住商混合；住宅至少 20 棟且商業少於 8 處 → 住宅為主；其餘待確認。
- 以上是未經全國校準的產品啟發式門檻，UI 一律標示「環境推估・資料有限」，不是官方分類、人流測量、治安或噪音分數。資料覆蓋率未知，不提供高可信度。
- 「活動較少」保留在五段刻度中，但不從缺少商店或零犯罪自動推定。未接入實地觀察前，不產生第 1 級。明確住宅建物只能支持住宅性質，不能證明安靜。
- 僅完整門牌定位結果採計；地址僅到區域時顯示待確認。空結果、請求失敗、Overpass remark（可能為部分結果）各自處理，不計為零風險。
- 營業時間只陳述 `opening_hours=24/7` 的地圖標記；不以酒吧分類推定深夜營業、不以複雜時段字串推定營業狀態。照明、人流與路線尚未實地確認。

來源定義：[OSM building](https://wiki.openstreetmap.org/wiki/Key:building)、[OSM opening_hours](https://wiki.openstreetmap.org/wiki/Key:opening_hours)。地圖資料需保留 © OpenStreetMap contributors attribution。

## 驗證

`npx tsx scripts/test-neighborhood-activity.ts`：缺資料、粗定位、分類、重複場所、距離篩選及营业時間。
`npm run test:crime-safety`：既有犯罪快照、計算與趨勢回歸。

## 後續資料接入

本次未新增町丁目犯罪快照、居民評論、照明或現場觀察。各縣部分罪種的町丁資料可獨立接入，不以缺少全罪種為排除理由。參考 `CRIME_DATA_COVERAGE_AUDIT.md` 的 2026-09-13 更正。

## 同日 UI 與犯罪明細補充

- 排名及破案率併入非東京左上統計卡；右上只顯示環境等級、刻度和結論，場所件數、夜間資訊、資料限制與來源移到雙卡下方的獨立展開區，避免撐高東京住宅卡。
- 新增警察廳 2023 年第 3、5 表原始件數，與既有 e-Stat 2023 年指標對齊。涵蓋 47 都道府縣、6 大類及 104 明細。前版只呈現竊盜、粗暴、凶惡三類比例，缺少知能、風俗、其他刑法犯，所以不滿 100%。
- `scripts/update-prefecture-crime-counts.py` 以 openpyxl 唯讀擷取官方 XLSX，逐項驗證明細和、分類和、47 縣全國和，再寫入 `src/data/prefectureCrimeCounts.json`。不以已四捨五入的百分比或人口率倒推件數。
- `npx tsx scripts/test-prefecture-crime-counts.ts` 對帳官方全國總數 703,351、千葉總數 37,538，以及原先 e-Stat 三項比例；年度不符不混用，退回比例說明。
- UI 六類均顯示件數、比例，可展開包含零件數的明細。比例由實際件數計算，顯示四捨五入可能不精確等於 100%；風俗犯是刑法分類，不是風俗店數量。

- 後續版面調整：非東京右卡保留場所件數，夜間描述、限制與來源直接置於卡片底部，不再另設環境展開列；東京繼續使用卡片下方的環境展開區。
