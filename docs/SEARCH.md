# 知識庫搜尋說明

租屋指南與買房置產兩個分頁的搜尋框，共用同一套比對邏輯：[`src/lib/search.ts`](../src/lib/search.ts)。

## 行為

| 使用者輸入 | 結果 |
| --- | --- |
| `敷金` | 找出所有提到敷金的項目 |
| `敷金 禮金` | 找出**同時**提到兩者的項目（AND，順序不拘） |
| `敷金　禮金` | 同上（全形空白、逗號、頓號都當分隔符） |
| `押金` | 也會找到寫「敷金」的內容（同義詞） |
| `代書` | 也會找到寫「司法書士」的內容 |

- 每個關鍵字之間是 **AND**：全部命中才會顯示。
- 單一關鍵字內部是 **OR**：命中任一同義寫法即可。
- 租屋分頁需輸入 **2 個字以上**才啟動搜尋；買房分頁 1 個字即啟動。

## 同義詞對照表

寫在 `src/lib/search.ts` 的 `SYNONYM_GROUPS`，同一組內的詞彼此等價。
目前涵蓋租屋初期費用、申請審查、退租，以及買房的價金、稅費、面積、物件型態與流程角色。

### 維護原則

1. **只放「講的是同一件事」的詞。** 制度上不同的東西不要放在一起——
   例如「手付金」是簽約時付的訂金，「頭期款」是自備款，兩者是分開的兩組。
2. **台灣慣用語可以對應日本制度**，即使只是功能相近（例如「代書 ↔ 司法書士」、
   「契稅 ↔ 不動產取得稅」）。這是為了讓台灣讀者搜得到，
   **不代表可以改寫內文的正式用詞**——內文仍要使用日本的正式名稱。
3. **新增知識庫內容時**，如果用了新的專有名詞，記得回來補一組同義詞。
4. 不要加入過於通用的詞（例如「費用」「日本」），會讓搜尋失去篩選效果。

### 加一組同義詞

在 `SYNONYM_GROUPS` 陣列裡加一行即可，順序不影響結果：

```ts
["定期借家", "定期租約", "定期契約"],
```

## 已知限制

- **沒有錯字容忍**：打錯字不會有結果（沒有模糊比對）。
- **沒有相關度排序**：命中的項目依原本的資料順序顯示，不做加權。
- **AND 可能過嚴**：例如「火災保險 更新」會查無資料——
  知識庫裡有火災保險、也有更新料，但沒有同時談這兩件事的段落。這是預期行為。
- **查不到不一定是搜尋壞掉**，可能是知識庫真的沒有那個內容。
  判斷方式：直接用單一關鍵字查，若仍無結果，就是內容缺口，該補資料而不是改搜尋。
